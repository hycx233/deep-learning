\begin{frame}{用小型 CNN 提取局部形态}
\begin{center}
$128\times128$ 输入\quad $\longrightarrow$\quad 三个卷积模块（16 / 32 / 64 通道）\\[1.1em]
全局平均池化\quad $\longrightarrow$\quad 三分类输出
\end{center}
\vspace{1.0em}
\begin{itemize}
\item 卷积层提取局部条带和块状形态，池化汇总空间信息。
\item 模型共有 \textbf{23,603 个参数}，适配当前标注规模。
\item 344 个结构形成 688 个窗口，同一结构的两个重复进入同一集合。
\end{itemize}
\end{frame}

\begin{frame}[fragile]{训练与最佳权重选择}
\textbf{加权交叉熵}处理类别不均衡，验证集 \textbf{Macro-F1} 选择轮次。
\begin{lstlisting}
logits = model(features)
loss = criterion(logits, labels)
if training:
    optimizer.zero_grad(set_to_none=True)
    loss.backward()
    optimizer.step()
\end{lstlisting}
\vspace{0.3em}
\small Adam，学习率 $10^{-3}$，dropout=0.3；第 20 轮早停，最佳权重来自第 12 轮。\par
\small 训练集更新参数，验证集选择权重，测试集评价最终表现。
\end{frame}
