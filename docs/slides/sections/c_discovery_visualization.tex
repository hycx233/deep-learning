\begin{frame}[fragile]{按有效像素计算重建误差}
\textbf{每个窗口使用自己的有效区域和像素数。}
\vspace{0.6em}
\begin{lstlisting}
valid_counts = window_mask.sum(dim=(1, 2))
squared_error = (prediction - target).square()[:, 0]
per_window = (squared_error * window_mask).sum(dim=(1, 2)) / valid_counts
\end{lstlisting}
\small \texttt{masked\_mse} 节选；调用方将有效 mask 与上三角 mask 取交集。\par
\vspace{0.6em}
\begin{itemize}
\item 数据缺口排除，对称像素计算一次，训练和打分共用规则。
\item 误差与接触强度的 Pearson 相关为 \textbf{0.828}，候选筛选明显受强度影响。
\end{itemize}
\end{frame}
