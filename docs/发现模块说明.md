# 任务二：自编码器与候选窗口打分

对应 issue #5。本模块只负责模型训练、重建误差打分和候选表输出；共享的 `.cool`
读取、深度归一化、O/E、环状窗口与正式空间分组仍由 #2 提供，避免三个任务各写一套预处理。

## 正式输入接口

从仓库根目录运行。输入沿用分类模块约定：

- `windows.csv` 至少包含 `window_id, chrom, start, end, sample_id, condition, replicate`。
- 训练背景还需要 `known_overlap` 布尔列（或可为空的 `structure_id`）和 #2 给出的
  `split=train/val/test`。脚本不会自行随机拆分相互重叠的滑窗。
- `arrays.npz` 的 `X` 为 `float32`、形状 `N×128×128` 的形态归一化窗口。
- 正式打分还需要一维 `intensity_scores`，来源应是 #2 的深度归一化 counts；它用于检查
  高重建误差是否只是高密度区域，不能用每个窗口单独缩放后的均值代替。

## 训练与打分

```bash
# 1. 只用 #2 给出的 WT_rep1 train 背景训练，val 选最佳轮次
python scripts/train_autoencoder.py \
  --windows-csv outputs/preprocessing/default/background/windows.csv \
  --arrays-npz outputs/preprocessing/default/background/windows.npz \
  --out-dir outputs/discovery/autoencoder \
  --sample-id WT_rep1 --epochs 30 --batch-size 8

# 2. 从 #2 的共享 100 bp 缓存生成 1 kb 步长的 WT_rep1 全基因组扫描输入
python scripts/prepare_discovery_scan.py \
  --sample-id WT_rep1 \
  --cache-dir data/cache/100bp \
  --structures-csv data/structures.csv \
  --out-dir outputs/discovery/scan_1kb

# 3. 对全部 4,642 个扫描窗口打分，保留前 1% 作为候选
python scripts/score_candidates.py \
  --checkpoint outputs/discovery/autoencoder/best.pt \
  --windows-csv outputs/discovery/scan_1kb/windows.csv \
  --arrays-npz outputs/discovery/scan_1kb/windows.npz \
  --out-dir outputs/discovery/candidates \
  --candidate-quantile 0.99
```

训练只读取 WT rep1 中排除已知结构后的 `train` 背景，用 `val` 损失选择权重。默认误差
只统计上三角，并排除主对角线及相邻一条，避免对称像素重复计数和主对角线主导结果。

主要输出：

```text
outputs/discovery/autoencoder/
├── best.pt
├── run.json
├── train_log.csv
└── training_windows.csv

outputs/discovery/candidates/
├── window_scores.csv
├── candidates.csv
├── latents.npz
├── score_examples.png
└── summary.json
```

`window_scores.csv` 保留全部扫描窗口；`candidates.csv` 只保留超过本次分位数阈值的窗口。
阈值是待结合已知结构和随机背景固定的本组规则，不代表普适生物学阈值。`latents.npz`
保存与 `window_id` 对齐的隐向量，供 #6 的 PCA 和 DBSCAN 使用。

## 2026-09-21 mask 修订后的正式运行结果

- 训练数据为 WT_rep1 的 24 个真实背景窗口：`train=17`、`val=4`、
  `test=3`；测试背景未参与训练或选轮次。
- loss 使用每个窗口的有效像素 mask 与固定上三角 mask 的交集，并按每个窗口自己的
  有效像素数求均值，数据缺口的填零区域不参与训练、选轮次或候选排序。
- 自编码在 CPU 上运行 30 轮，最佳轮次 25，验证 masked MSE 为
  `0.022307`；模型有 1,129,553 个可训练参数。
- 按 1 kb 步长扫描整条 4,641,652 bp 环状染色体，实际导出 4,642 个窗口。
  99% 分位数阈值为 `0.046336`，保留 47 个候选，其中 36 个窗口与已知
  结构相交，11 个不相交。
- top 1% 候选召回 21/344 个已知结构（`6.1%`）。这不是分类准确率，
  只表示已知结构附近是否出现高重建误差窗口。
- 重建误差与深度归一化强度的 Pearson 相关为 `0.828`、Spearman 相关为
  `0.765`。因此当前高分明显受接触密度影响，不能直接宣称是新结构；
  #6 必须结合隐向量簇、已知结构重叠和独立位置数继续筛选。

小型结果摘要和已检查的对照图保存到 `docs/results/discovery/`；完整窗口、
权重和隐向量保留在被 Git 忽略的 `outputs/discovery/`。

## 历史烟雾验证（不作为正式结果）

可以从 WT rep1 读取少量真实局部 counts，检查 HDF5 局部读取、模型和输出是否连通：

```bash
python scripts/make_discovery_smoke_windows.py \
  --structures-csv data/structures.csv \
  --out-dir outputs/discovery/smoke_input

python scripts/train_autoencoder.py \
  --windows-csv outputs/discovery/smoke_input/windows.csv \
  --arrays-npz outputs/discovery/smoke_input/windows.npz \
  --out-dir outputs/discovery/smoke_model \
  --epochs 2 --device cpu

python scripts/score_candidates.py \
  --checkpoint outputs/discovery/smoke_model/best.pt \
  --windows-csv outputs/discovery/smoke_input/windows.csv \
  --arrays-npz outputs/discovery/smoke_input/windows.npz \
  --out-dir outputs/discovery/smoke_scores \
  --candidate-quantile 0.8 --device cpu
```

烟雾窗口虽来自真实 WT rep1，但只做 `log1p(raw counts)` 和一次全局截断缩放，
没有正式深度归一化或 O/E。它仅用于调试入口，报告应使用上述正式运行。
