# 任务二：候选聚类与候选表

对应 issue #6，依赖 #5 保存的全部扫描分数和 32 维自编码器隐向量。本模块不重新训练
编码器，候选、已知结构参考和随机背景都经过同一个固定编码器和同一套标准化、PCA
变换，再使用 DBSCAN 聚类。

## 运行方法

先完成 `docs/发现模块说明.md` 中的正式训练和全基因组打分，然后从仓库根目录运行：

```bash
python scripts/cluster_candidates.py \
  --scores-csv outputs/discovery/candidates/window_scores.csv \
  --latents-npz outputs/discovery/candidates/latents.npz \
  --windows-npz outputs/discovery/scan_1kb/windows.npz \
  --structures-csv data/structures.csv \
  --pca-components 10 --eps 2.5 --min-samples 5 \
  --background-count 200 --seed 20260920 \
  --out-dir outputs/discovery/clustering
```

已知参考使用每条标注结构中心最近的 1 kb 扫描位置；多个标注落到同一扫描位置时合并，
避免重复隐向量人为增加 DBSCAN 密度。背景从既非候选也非已知参考的位置中固定随机种子
抽取。PCA 前按 32 个隐向量维度标准化，并对 PCA 坐标白化，使 DBSCAN 距离不被第一
主成分的量纲单独主导。

## 输出与判定规则

```text
outputs/discovery/clustering/
├── candidate_clusters.csv
├── cluster_members.csv
├── clusters.csv
├── known_reference_mapping.csv
├── pca.npz
├── classification.json
├── summary.json
├── pca_groups.png
└── cluster_representatives.png
```

`candidate_clusters.csv` 包含 ID、坐标、长度、簇、候选分数、已知结构关系和最近已知
参考的 PCA 距离，同时预留 `rep2_window_id`、`replicate_correlation` 和
`reproducibility_status` 给 #9。相互重叠的候选扫描窗口合并为一个独立位置后再统计
簇大小，不能把同一处连续的 1 kb 步长窗口当成多个发现。

本组“疑似新簇”必须同时满足：至少 5 个互不重叠的独立候选位置；簇内没有已知参考
成员；所有候选区间均不与已知结构重叠。DBSCAN 的 `-1` 是噪声，绝不作为一个簇。
满足规则也只表示需要 #9 跨重复验证的候选，不等于生物学新结构。
