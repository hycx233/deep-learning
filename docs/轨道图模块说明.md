# 任务三：三条件四面板全基因组轨道图

对应 issue #7。条件固定为 WT、ΔstpA（代码 `DstpA`）和 ΔhnsΔstpA（代码
`DhnsDstpA`），每种两个重复。

## 信号定义

Cooler 文件采用 `symmetric-upper` 存储。本模块不重复读取 10 bp 原始像素，
直接复用 #2 的 `data/cache/100bp/` 缓存：

- 非对角像素的 counts 分别累加到两个端点；
- 对角像素只累加一次；
- 使用缓存中的 100 bp `marginal`，并将无效 bin 置零；
- 每个重复乘以 #2 记录的 `depth_factor = 1,000,000 / 上三角唯一 counts 总量`；
- 条件平均值在两个已经归一化的重复之间取算术平均。

显示时可用 `--sqrt-display` 压缩动态范围，但保存的轨道数组仍为线性归一化信号。
第一面板的灰色虚线是六个归一化轨道的全基因组中位数，仅作为显示基线，不是统计阈值。

## 构建轨道

先执行 #2 的 `prepare_data.py`生成六样本缓存，再从仓库根目录运行：

```bash
python scripts/build_contact_tracks.py \
  --samples-csv data/samples.csv \
  --cache-dir data/cache/100bp \
  --out-dir outputs/tracks/contact_signal
```

脚本读取 #2 的稀疏工作缓存和已计算的边际信号，不构造全基因组稠密矩阵。主要输出：

```text
outputs/tracks/contact_signal/
├── contact_tracks.npz
├── sample_summary.csv
├── samples_used.csv
└── run.json
```

`sample_summary.csv` 记录六个样本的像素数、唯一 counts 总量、深度因子、
有效 bin 数和归一化后轨道总量；`samples_used.csv` 保存本次实际使用的清单快照。

## 先画样图，再批量输出

先检查一张 10 kb 样图：

```bash
python scripts/plot_tracks.py \
  --tracks-npz outputs/tracks/contact_signal/contact_tracks.npz \
  --start 0 --end 10000 \
  --sqrt-display \
  --out-dir outputs/tracks/sample
```

四个面板依次为：六个重复曲线与灰色基线、三个条件平均信号、蓝色基因轨道、橙色
CHIN/OPCID 结构轨道。确认坐标、名称、图例和色彩后再生成全套：

```bash
python scripts/plot_tracks.py \
  --tracks-npz outputs/tracks/contact_signal/contact_tracks.npz \
  --segment-bp 10000 \
  --sqrt-display \
  --out-dir outputs/tracks/all
```

长度 4,641,652 bp 会输出 465 张，最后一张覆盖 `[4,640,000, 4,641,652)`。正式运行后
应人工检查第一张、最后一张，并从中挑 3–5 张名称和坐标清楚的代表图复制到
`docs/results/`。出图目录同时保存 `genes_used.csv`、`structures_used.csv` 和 `run.json`；
批量图片留在忽略的 `outputs/`，不直接提交 Git。

## 正式运行结果（2026-09-20）

正式运行使用六个真实样本与 #2 的 100 bp 共享缓存。六条归一化轨道总量为
1,974,406.10–1,986,597.14；该数值约为一百万的两倍，是因为边际信号会把每个
非对角接触分别计入两个端点，不应解释为原始 reads 数。

- 共生成 465 张 10 kb 轨道图，首区间为 `[0, 10,000)`，末区间为
  `[4,640,000, 4,641,652)`；
- 首图、末图以及 4 张代表图均已人工打开检查，坐标、图例、基因和结构标注可读；
- 最后一个不完整 100 bp bin 被标为无效并留白，没有被画成假性的零信号下降；
- 正式运行对应代码版本为 `379bb4c49573aff800743faad074ed2b75464ab9`；
- `python -m unittest discover -s tests -p "test_*.py"` 共 15 项通过，相关脚本也通过
  `compileall` 检查。

可提交的小型正式结果位于 `docs/results/tracks/`：`contact_run.json` 和
