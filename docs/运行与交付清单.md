### 任务二：背景训练 → 全基因组打分 → 聚类 → 跨重复验证

依次执行[发现模块说明](发现模块说明.md)“训练与打分”的三条正式命令：

1. `train_autoencoder.py` 读取 `outputs/preprocessing/default/background/`，仅用 WT_rep1 的 17 个 train 背景训练、4 个 val 选轮次，保留 3 个 test；读取每窗有效 mask。
2. `prepare_discovery_scan.py` 读取共享缓存，按 1 kb 步长生成 `outputs/discovery/scan_1kb/` 的 4,642 个窗口。
3. `score_candidates.py` 用 `outputs/discovery/autoencoder/best.pt` 打分，`--candidate-quantile 0.99`，输出至 `outputs/discovery/candidates/`。

随后聚类，**正式参数是 `eps=3.0`**，以[正式运行摘要](results/clustering/summary.json)为准，不沿用旧示例或脚本默认的 2.5：

```bash
python scripts/cluster_candidates.py \
  --scores-csv outputs/discovery/candidates/window_scores.csv \
  --latents-npz outputs/discovery/candidates/latents.npz \
  --windows-npz outputs/discovery/scan_1kb/windows.npz \
  --structures-csv data/structures.csv \
  --pca-components 10 --eps 3.0 --min-samples 5 \
  --background-count 200 --seed 20260920 \
  --out-dir outputs/discovery/clustering
```

mask 修订后的正式结果为 **47 个候选、21/344 个已知结构被召回**；47 个窗口合并后为 10 个独立位置，没有满足本组规则的新簇。重建误差仍与强度明显相关，不能把高分或 DBSCAN 噪声称为新结构。方法见[候选聚类说明](候选聚类说明.md)。

[#9 跨重复验证](https://github.com/hycx233/deep-learning/issues/9) 已由 B 完成，通过 #23/#19 合入主分支，issue 已关闭。47 个候选按重叠关系合为 10 个独立位置，比较每个位置预先固定的 rep1 代表窗口；Pearson 中位数为 0.8572。逐位置表、47 行衔接表、配对图和已知结构去重召回见[验证结果](results/validation/README.md)。`candidate_clusters.csv` 中的 `pending_P09` 是聚类阶段生成时的历史状态；它不是当前结论，也不表示 47 个窗口逐一检验。4 个代表窗口存在共同无效区域，解释限于共同有效部分；本次可信新结构为 0。
